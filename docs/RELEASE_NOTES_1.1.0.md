# RavnDock v1.1.0

RavnDock is a private, local AI chat app for your own files.

## Highlights

- Choose a local folder and create a private knowledge base.
- Ask questions using local chat and document retrieval.
- See citations for PDF pages, PowerPoint slides, spreadsheet cells, document
  sections, CSV rows, and text lines.
- Choose Performance, Balanced, High Quality, or another installed local model.
- Monitor memory, CPU, GPU, storage, model speed, and request statistics.
- Review knowledge-base files, synchronization status, and source passages.
- Use light or dark mode with a compact macOS-style interface.

## Requirements

- Apple Silicon Mac (`arm64`).
- At least 16 GB unified memory recommended.
- The primary reference device is a 2021 MacBook Pro M1 with 16 GB memory.
- Intel Macs are not supported by this release.

## Important first-launch note

RavnDock is independently distributed and not Apple-signed. On first launch, use
**System Settings → Privacy & Security → Open Anyway**.

The DMG is free to download from GitHub. Model and software downloads inside the
app occur only after the user approves them.

## Privacy

Prompts and selected document contents are processed locally and are never
intentionally uploaded. Read the repository [privacy policy](PRIVACY_POLICY.md).
