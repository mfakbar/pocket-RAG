# RavnDock Usability Test

Ask each participant to complete these tasks without guidance. Record where they hesitate, what they expect, and whether they recover after an error.

1. Create a knowledge base from a local folder and describe what it contains.
2. Sync the folder, then explain what changed after the sync.
3. Ask a question that requires a cited answer and open a cited-passage preview.
4. Start a model-only chat, then switch back to using files.
5. Find the active model, change reading mode, and open Monitor.

Success criteria: the participant completes each task, understands whether RavnDock is ready, and can explain where their documents are being used.
