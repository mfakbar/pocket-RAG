# App Store Screenshots

Apple currently accepts one to ten Mac screenshots in PNG or JPEG with no alpha
channel. Use one consistent 16:10 size: 1280x800, 1440x900, 2560x1600, or 2880x1800.

Capture at least Home, Chat with grouped citations, and Monitor. Use a sanitized demo
folder and demo conversations. Do not show personal file paths, company-confidential
documents, browser windows, desktop notifications, or unrelated applications.
